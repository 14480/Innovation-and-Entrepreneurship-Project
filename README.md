# 创新创业大赛项目文件

「创新创业大赛」参赛材料仓库。

## 用途

集中存放参赛项目的计划书、演示材料与相关素材，便于版本追踪与云端备份。

## 目录说明

建议按材料类型归档，便于多人协作与快速检索：

- `docs/`：计划书、研究报告、答辩稿等文档
- `slides/`：路演 PPT、演示视频与演讲素材
- `assets/`：图片、图表、字体等静态资源
- `src/`：可选的演示代码或原型

## 贡献

提交材料或修改文档前，请阅读 [CONTRIBUTING.md](CONTRIBUTING.md)，并遵循分支命名与提交信息约定。

## 约定

- `.rivet/` 为本机智能开发环境的运行时目录，已由 `.gitignore` 排除，不纳入版本控制。
- Office 临时锁文件（`~$*`）、系统杂项（`Thumbs.db`、`desktop.ini`）同样不入库。
